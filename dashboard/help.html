TROUBLESHOOTING

Quick answers

Focused checks for the most common local questions.

01The dashboard says Gateway unavailableCheck local service health

Run docker compose ps and confirm Gateway, PostgreSQL, and Redis are healthy. Then open the Gateway health endpoint on port 8080.

02Why does the second request say CACHE?Tenant-private exact caching

An identical successful request for the same tenant is returned from the local exact cache. Change the prompt or tenant to create a cache miss.

03Are provider credentials stored?Request-scoped BYOK boundary

No. The provider key stays in browser memory for the request, travels in X-Provider-Key, and is not written to the usage ledger.

04Where is the complete architecture?Long-form project reference

Open the Docs page for service ownership, request flow, security, delivery, monitoring, verified scope, and repository documentation paths.
